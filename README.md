
# Sistema de Gestion de Usuarios CRUD

## Descripcion

Aplicacion web para administrar usuarios mediante
las operaciones CRUD: crear, consultar, actualizar
y eliminar registros.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## Funcionalidades

- Registrar usuarios.
- Consultar usuarios registrados.
- Buscar usuarios.
- Editar informacion.
- Eliminar usuarios.
- Validar los datos del formulario.
- Guardar informacion en LocalStorage.

## Instalacion

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar index.html en un navegador.
